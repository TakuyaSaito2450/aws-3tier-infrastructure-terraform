## 概要
このリポジトリは、以前作成したaws-iac-portfolio-terraform（VPC設計からALBによる負荷分散・マルチAZ構成までを扱った基礎構成）を発展させ、より本番運用を意識した3層Web基盤をTerraformでコード化したものです。

ALB＋EC2（Auto Scaling）＋RDSの3層構成に加え、監視・通知の仕組みまでを含めて一括で構築・破棄できるようにしています。前作で「今後の構成予定」として挙げていた以下の項目を、本リポジトリで実際に構築しました。

プライベートサブネットを使ったRDS構成
CloudWatchによるログ監視の自動化
EC2をプライベートサブネットに移行し、NATゲートウェイ経由でアウトバウンド通信を制御する構成

運用保守で扱ってきた構成を、手作業ではなくコードで再現・拡張できる形に置き換えることを目的に、段階的に発展させながら作成しました。---
